## Descripción

Este repositorio reúne los proyectos desarrollados para el Trabajo Práctico N°2
de Práctica Profesionalizante I: un CV, un formulario con validación, una
landing page y una guía de estilo, cada uno maquetado en HTML5, CSS3 y
Bootstrap 5.

## Estructura del repositorio

```
├── cv/                  → Plantilla de CV (carátula del portafolio)
│   ├── index.html
│   └── css/style.css
├── formulario/           → "Refugio del Cóndor" — formulario de reserva con validación
│   ├── index.html
│   └── css/style.css
├── guia-estilo/           → "Casa Terracota" — guía de estilo en HTML5 + CSS puro
│   ├── index.html
│   └── css/style.css
├── landing-page/         → "Cumbre Libre" — landing page de agencia de trekking
│   ├── index.html
│   └── css/style.css
└── README.md
```

## Cómo ver cada proyecto

Cada carpeta es independiente y se abre por separado desde su `index.html`.
No requieren instalación: se pueden abrir directamente en el navegador, o con
la extensión **Live Server** de VS Code para mejor experiencia.

| Proyecto | Carpeta | Tecnologías |
|---|---|---|
| CV | [`/cv`](./cv) | HTML5, Bootstrap 5 |
| Formulario | [`/formulario`](./formulario) | HTML5, Bootstrap 5, JavaScript (validación) |
| Guía de estilo | [`/guia-estilo`](./guia-estilo) | HTML5, CSS3 puro |
| Landing page | [`/landing-page`](./landing-page) | HTML5, Bootstrap 5 |

## Tecnologías utilizadas

- **HTML5** — estructura semántica de cada página.
- **CSS3** — estilos propios, variables de color, responsive con media queries.
- **Bootstrap 5** — grillas, navbar, carrusel y modal en formulario y landing.
- **Git y GitHub** — control de versiones y publicación del repositorio.
